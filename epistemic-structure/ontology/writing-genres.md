# 글 갈래

## 정의

이 레포가 규약을 나눠 세우는 글의 종류. 갈래마다 독자, 목적, 허용되는 문체가 달라 규약을 따로 둔다.

| 갈래 | 정의 | 예 |
|------|------|-----|
| 평서문 기록 | 사실, 판단, 절차를 독자에게 전달하는 글 | 설계 문서, 분석 보고, 지침, 커밋 메시지, 사실과 판단을 전하는 대화 응답 |
| 회고 | 지나간 작업이나 글을 돌아보며 판단과 교훈을 남기는 글 | 작업 회고, 글쓰기 회고 |
| 창작 | 허구의 세계와 인물을 서술하는 글 | 소설 |
| 주석 | 코드나 설정 곁에서 그 의도와 함정을 설명하는 짧은 글 | 소스 코드 주석, in-source 문서, 설정 파일 주석 |

## 경계

- 한 글이 여러 갈래에 걸치면 주된 목적의 갈래 규약을 따르고, 부분마다 해당 갈래 규약을 겹쳐 적용한다. 예를 들어 회고 안의 사실 서술은 평서문 기록 규약을 따른다.
