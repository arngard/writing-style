# 평서문 기록은 정확하고 담백하게, 정보를 잃지 않게 쓴다

평서문 기록(문서, 보고, 분석, 커밋 메시지, 사실과 판단을 전하는 대화 응답)의 정식 규약. 창작과 회고는 갈래가 달라 별도 규약을 둔다. 갈래 정의는 [writing-genres.md](../ontology/writing-genres.md). 조항은 모두 [plain-prose-rules/](plain-prose-rules/AGENTS.md)의 규칙 문서에 두고, 여기에는 절마다 원리 요지와 규칙 문서 링크를 둔다. 규칙 문서도 이 규약의 일부라 함께 읽는다.
