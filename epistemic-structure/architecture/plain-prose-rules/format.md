# 서식과 기호는 절제한다

평서문 기록 규약 [plain-prose-rules.md](../plain-prose-rules.md)의 서식과 기호 조항이다.

문장 부호는 ASCII를 우선하고, 규칙과 설명에서 부호 자체를 가리킬 때는 원형 대신 이름과 코드포인트로 쓴다(예: 가운뎃점(U+00B7)).

## 서식 강조는 강한 경고, 금지, 주의에만 쓴다 `emphasis-restraint`

- 굵게, 기울임 같은 서식 강조는 강한 경고, 금지, 주의에만 쓴다. 남발하면 진짜 경고가 힘을 잃는다.

## 이모지와 장식용 특수기호, 항목 표시 화살표를 쓰지 않는다 `no-decorative-symbols`

- 이모지와 장식용 특수기호, 항목 표시로 쓰는 화살표를 쓰지 않는다. 목록은 `-` 목록과 번호 목록으로 쓴다.

### 후보 검출 패턴

```regex
[\U0001F000-\U0001FAFF\u2600-\u27BF\u2B00-\u2BFF\uFE0F\u203C\u2049]
[\u2022\u2023\u2043\u203B\u25A0-\u25FF\u2605\u2606]
(?m)^[ \t]*(?:[-*+][ \t]+)?(?:->|=>|[\u2190-\u21FF\u27F5-\u27FF])[ \t]
```

## 비ASCII 부호는 ASCII 표기로 바꾼다 `ascii-punctuation`

문장 부호는 ASCII를 우선한다.

| 부호 | 바꾸는 표기 |
|------|-------------|
| 가운뎃점(U+00B7) | 쉼표 |
| em dash(U+2014) | 공백 하이픈 공백(` - `)이나 문장 분리 |
| 화살표(U+2192) | 흐름 표기에 한해 `->`. 항목 표시로는 쓰지 않는다 |

### 후보 검출 패턴

```regex
[\u00B7\u2014\u2192]
```

## 부호 자체를 가리킬 때는 이름과 코드포인트로 쓴다 `symbol-name-codepoint`

규칙과 설명에서 부호 자체를 가리킬 때는 원형 대신 이름과 코드포인트로 쓴다. 금지 사례의 "고치기 전" 예시도 원형을 보이지 않고 서술로 푼다. 원형을 백틱으로 감싸면 ASCII 부호 검사만 피할 뿐 비ASCII 문자는 파일에 남는다.

### 부호 자체를 가리키는 원형은 세 영역에서만 쓴다

규칙과 설명에서 부호 자체를 가리킬 때 원형을 그대로 쓰는 곳은 다음 영역뿐이다.

- 인용 블록
- 레퍼런스: `reference/` 아래 원본과 인용한 외부 자료
- UI 구현체: 화면에 표시되는 문자열을 담은 코드와 리소스
