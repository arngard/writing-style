# 평서문 기록 규약 하위 문서 디스크립터

> [plain-prose-rules.md](../plain-prose-rules.md)의 하위 문서. 조항이 계속 늘고 절마다 따로 읽히는 절을 하위 문서로 나눈다 (ref: [document-units.md](../../../AGENTS/epistemic-rules/document-units.md) "수평 확장은 하위 문서로 분할한다").
> 상위 문서는 절마다 원리 요지와 링크를 두고, 나눈 절의 조항 전체는 이 폴더의 문서가 담는다. 이 폴더의 문서도 정식 규약의 일부라 상위 문서와 함께 읽는다.
