# 평서문 기록 규약 규칙 문서 디스크립터

> [plain-prose-rules.md](../plain-prose-rules.md)의 규칙 문서. 상위 문서는 절마다 원리 요지와 규칙 문서 링크를 두고, 조항 본문은 이 폴더의 규칙 문서가 담는다. 규칙 문서도 정식 규약의 일부라 상위 문서와 함께 읽는다.
> 규칙 문서는 관심사 하나의 조항을 모은다. 윤문의 의미 수정에서는 규칙 문서 몇 개를 검토 묶음 하나로 모아 검토자 한 명에게 맡긴다(묶음 구성은 [polish.md](../../../implementation/polishing/workflows/polish.md) 4단계). 규칙 하나가 `##` 절 하나이고, 절 제목 끝에 규칙 이름(영문 소문자 케밥 케이스, 레포 전체에서 하나)을 인라인 코드로 붙인다. 규칙의 예시는 [implementation/polishing/explanations/](../../../implementation/polishing/explanations/)의 같은 이름 문서에 두고, 규칙 절의 `### 설명`에서 링크한다.
