# 옛 표기 cf., ref.를 고치는 방법

옛 표기 `cf.`, `ref.`를 [reference-markers.md](reference-markers.md)의 규정으로 고치는 절차와 형태별 처리. 표지를 기계적으로 바꿔 달지 않고 참조마다 판정한다.

## 참조 하나는 세 단계로 고친다

1. 링크를 본문 문장에 녹일 수 있으면 녹이고 표지를 지운다.
2. 녹일 수 없으면 이 문서가 대상에 기대는 방식으로 `ref:`, `sub:`, `see:` 중 하나를 고른다. 옛 표기가 무엇이었는지는 판정 근거가 아니다. 옛 `cf.`도 근거면 `ref:`이고, 옛 `ref.`도 기대지 않는 대상이면 `see:`다.
3. 표지 뒤가 링크나 출처로 시작하도록 형태를 맞춘다.

## 형태별 처리

| 옛 형태 | 처리 |
|---------|------|
| 문장 끝 괄호 `... 한다 (cf. [x](x)).` | 형태는 두고 표지를 판정해 바꾼다 |
| 줄 앞 표지와 링크, 여러 링크 나열 | 형태는 두고 표지를 판정해 바꾼다. 범주가 섞였으면 표지를 나눈다 |
| 목록 항목과 설명 `- cf. [x](x) - 설명` | 형태는 두고 표지를 판정해 바꾼다. 동조, 반대 같은 입장은 설명에 남긴다 |
| 원자료 출처 줄 `- cf. raw: [x](x)` | 원천이므로 `ref:`로 바꾸고 `raw:` 이름표는 설명이나 링크 제목으로 옮긴다 |
| 표지 뒤 문장 `cf. 업계 비교는 [x](x) 참조.` | 표지를 지우고 링크를 녹인 문장으로 다듬는다 |
| 표지 뒤 제목이나 슬러그만 있음 | 대상 문서를 찾아 링크로 바꾼 뒤 표지를 판정한다 |
| 참조가 아닌 서술 항목 `- cf. **사례**: 서술` | 참조가 아니므로 `cf.`를 지우고 일반 목록 항목으로 둔다 |
| 링크할 수 없는 출처 `ref. 사용자 짚음 2026-05-19` | `ref: 사용자 지적 2026-05-19`처럼 콜론 형태로 바꾼다 |
| 코드 주석 `(cf. strategy/AGENTS.md)` | 같은 판정으로 표지를 바꾸고 경로는 평문으로 둔다 |
| 상세 문서를 가리키는 화살표 포인터 `... 요약. -> [x](x)` | 흐름을 잇는 화살표가 아니면 따로 둔 참조이므로 의미대로 표지로 바꾼다 |
| 표지 없이 출처 링크만 둔 각주 `[^x]: [제목](url)` | 따로 둔 참조이므로 판정한 표지를 단다. 각주 안에서 링크를 문장에 녹였으면 표지를 달지 않는다 |
| 같은 문서의 절을 가리키는 `(cf. 시장 사실)`, `cf. 위 "절"` | 문서 간 참조와 같이 판정해 표지를 바꾼다. 지시어는 지우지 않는다 |
| 표지 없이 지시어로 조준한 `(위 "절")` | 참조 표지가 아니라 지시어 조준이므로 그대로 둔다 |
| 순서나 위치로 가리킨 `인지 해석 셋째 문단`, `위 둘째 항목` | 가리키는 부분을 열어 이름이나 그 문단을 여는 구체적 문구로 바꾼다 |
| 표지 뒤 이름표 `- cf. 정면 반박: 제목 (화자)` | 이름표는 두고 표지만 판정해 바꾼다 |

## 고치는 곳과 두는 곳

- 규약을 담은 코드 펜스(출력 템플릿, 규정 예시) 안의 옛 표기는 고친다. 그 펜스는 규약의 일부라 새 표기를 따라야 한다.
- 문서 끝 "참고" 절은 이름을 그대로 두고 절 안 항목의 표지만 판정해 바꾼다. 절 이름과 뜻이 같은 표지 `cf.`(참고)를 없앴어도 그 절은 여전히 참고 자료를 모은 자리다.
- 외부 자료를 인제스트한 원문, 인용 블록, 원문을 옮긴 코드 펜스는 원래대로 둔다. 남의 글이라 고치면 원문이 훼손된다. 레포 자신의 안내문을 인용 블록 모양으로 둔 것(디스크립터 머리의 `>` 안내 등)은 남의 글이 아니므로 고친다.
