# 서식과 기호 규칙의 설명

평서문 기록 규약의 서식과 기호 규칙 문서 [format.md](../../../epistemic-structure/architecture/plain-prose-rules/format.md)의 규칙을 실제 문장에 적용한 예시다. 절마다 `규칙:` 줄이 그 예시가 보이는 규칙의 이름을 적는다.

예시는 규정을 보이기 위해 만든 문장이며, 이 문서도 규정을 따르므로 비ASCII 부호는 이름과 코드포인트로 적는다.

## 부호 자체를 가리킬 때는 이름과 코드포인트로 쓴다

규칙: `symbol-name-codepoint`

| 고치기 전 | 고친 뒤 | 이유 |
|-----------|---------|------|
| 가운뎃점 원형을 백틱으로 감싸 "대신 쉼표를 쓴다"로 이은 문장 | `가운뎃점(U+00B7) 대신 쉼표를 쓴다.` | 백틱 안의 원형도 파일에 남는다. |
| 금지 예시 줄에 "읽기", "쓰기", "실행"을 가운뎃점 원형으로 이어 그대로 보인 것 | `금지: "읽기", "쓰기", "실행"을 가운뎃점(U+00B7)으로 이은 나열` | 금지 사례를 보이려고 원형을 쓰면 막으려던 문자가 파일에 남는다. |
