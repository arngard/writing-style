# 문장 부호의 ASCII 표기

문장 부호는 ASCII를 우선한다. 아래 규정은 그 기준을 실제 문장에 적용한 것이다. 예시는 규정을 보이기 위해 만든 문장이며, 이 문서도 규정을 따르므로 비ASCII 부호는 이름과 코드포인트로 적는다.

## 비ASCII 부호는 ASCII 표기로 바꾼다

| 부호 | 바꾸는 표기 |
|------|-------------|
| 가운뎃점(U+00B7) | 쉼표 |
| em dash(U+2014) | 공백 하이픈 공백(` - `)이나 문장 분리 |
| 화살표(U+2192) | 흐름 표기에 한해 `->`. 항목 표시로는 쓰지 않는다 |

## 부호 자체를 가리킬 때는 이름과 코드포인트로 쓴다

규칙과 설명에서 부호 자체를 가리킬 때는 원형 대신 이름과 코드포인트로 쓴다. 금지 사례의 "고치기 전" 예시도 원형을 보이지 않고 서술로 푼다. 원형을 백틱으로 감싸면 ASCII 부호 검사만 피할 뿐 비ASCII 문자는 파일에 남는다.

| 고치기 전 | 고친 뒤 | 이유 |
|-----------|---------|------|
| 가운뎃점 원형을 백틱으로 감싸 "대신 쉼표를 쓴다"로 이은 문장 | `가운뎃점(U+00B7) 대신 쉼표를 쓴다.` | 백틱 안의 원형도 파일에 남는다. |
| 금지 예시 줄에 "읽기", "쓰기", "실행"을 가운뎃점 원형으로 이어 그대로 보인 것 | `금지: "읽기", "쓰기", "실행"을 가운뎃점(U+00B7)으로 이은 나열` | 금지 사례를 보이려고 원형을 쓰면 막으려던 문자가 파일에 남는다. |

## 부호 자체를 가리키는 원형은 세 영역에서만 쓴다

규칙과 설명에서 부호 자체를 가리킬 때 원형을 그대로 쓰는 곳은 다음 영역뿐이다.

- 인용 블록
- 레퍼런스: `reference/` 아래 원본과 인용한 외부 자료
- UI 구현체: 화면에 표시되는 문자열을 담은 코드와 리소스
