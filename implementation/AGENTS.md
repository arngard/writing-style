# 구현 프로젝트 디스크립터

> 정식 규약을 글에 적용하는 수단의 보관 영역. 하위 폴더 하나가 하위 프로젝트 하나이고, 윤문 하위 프로젝트 `revision/`이 규칙의 설명(예시), 기계 규칙, 도구, 워크플로, 윤문 스킬 원본을 담는다. 규칙 본문은 [epistemic-structure/architecture/](../epistemic-structure/architecture/AGENTS.md)에 둔다. 이 워크스페이스에서 담는 것은 부모 문서 [implementation.md](../implementation.md)가 안내한다.
> "어떤 하위 프로젝트가 존재하는가"의 SSOT(single source of truth)는 파일시스템이다 (ref: [AGENTS/epistemic-rules/folder-structure.md](../AGENTS/epistemic-rules/folder-structure.md) "폴더 구조와 디스크립터").
